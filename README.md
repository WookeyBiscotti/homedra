# Interior CAD Planner

Веб-приложение для визуального проектирования интерьеров и экстерьеров с CAD-ограничениями на стены и поддержкой нескольких этажей.

## Запуск

```bash
npm install --legacy-peer-deps
npm run dev
```

## Возможности MVP

- 2D-редактор планов (Konva): стены, вершины, сетка, размеры
- Ограничения через solver [JS.Sketcher](https://github.com/xibyte/jsketcher): фиксированная длина, якорь вершины, горизонталь/вертикаль
- Пиктограммы ограничений на стенах и вершинах (иконки из jsketcher)
- При перетаскивании вершины locked-стены сохраняют длину
- Несколько этажей
- 3D-вид (Three.js): интерьер / экстерьер
- Сохранение в localStorage, экспорт/импорт JSON, undo/redo

## Constraint solver

Код солвера вендорится из jsketcher в `vendor/jsketcher/` (см. LICENSE). Адаптер: `src/engine/constraints/solver.ts`.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| V | Выбор |
| W | Стена |
| D | Дверь |
| O | Проём |
| N | Окно |
| S | Лестница |
| F | Модель (каталог / NASA / библиотеки / свой GLB) |
| L | Фикс. длина |
| P | Фикс. точка |
| H | Горизонталь |
| I | Вертикаль |
| Ctrl+Z / Ctrl+Y | Отмена / повтор |
| Delete | Удалить выделение |
| Esc | Отменить черновик стены / проёма |
